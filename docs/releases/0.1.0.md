# 0.1.0

- Generate Spirits automatically from valid input; check payment QRs in the background.
- Keep avatar downloads available if a QR check fails, with a QR retry action.
- Cycle through ten public, disposable test-network examples.
- Support Node 24 and modern browsers, using ESM packages.

The `spirits-v0` artwork and mappings remain experimental. Recognition is a design goal, not a measured guarantee. Print reliability is unvalidated.
