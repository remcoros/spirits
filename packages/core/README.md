# @remcoros/spirits

This package renders deterministic ghost avatars from BIP352 public addresses in Node 24 and modern browsers. The v0 artwork is experimental. The core needs no private keys, network, filesystem, DOM or canvas.

```ts
import { createSpirit, deriveSpirit, renderSpirit, parseAddress, artwork } from '@remcoros/spirits';
const { svg, recipe } = createSpirit(address, { size: 512 });
```

`createSpirit` validates a v0 `sp`/`tsp` address and returns a self-contained SVG and portable recipe. `deriveSpirit` returns the recipe; `renderSpirit` renders it. `parseAddress` returns the canonical address and public keys. Invalid inputs throw `SpiritAddressError` with an error code.

`encodeAddress` encodes public keys you have already derived. It does not create wallet labels.

`renderAsset`, `assetName`, `CHARACTER_GROUPS`, `artwork`, and `varietyBudget` support development tools and ports. All original assets are also available in `assets/spirits-v0.json`.

For browser PNG conversion, use `import {svgToPng} from '@remcoros/spirits/browser'` and pass SVG generated by this library.

The scan key determines the character. Both public keys select the small label variations. Artwork has its own version and may change during v0. Characters can look alike and do not prove ownership. The package does not provide a directory or reversible short names.
