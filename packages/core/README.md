# @spirits/core

Experimental v0 deterministic ghost avatars for BIP352 public addresses. No private keys, network, filesystem, DOM or canvas are required for the core.

```ts
import { createSpirit, deriveSpirit, renderSpirit, parseAddress, artwork } from '@spirits/core';
const { svg, recipe } = createSpirit(address, { size: 512 });
```

`createSpirit` validates a v0 `sp`/`tsp` address and returns a self-contained SVG and portable recipe. `deriveSpirit` returns the recipe alone; `renderSpirit` renders it. `parseAddress` returns the canonical address and public keys. Invalid inputs throw `SpiritAddressError` with an error code. `encodeAddress` encodes already-derived public keys; it does not create wallet labels.

`renderAsset`, `assetName`, `CHARACTER_GROUPS`, `artwork`, and `varietyBudget` support development tools and ports. All original assets are also available in `assets/spirits-v0.json`.

Browser-only PNG conversion: `import {svgToPng} from '@spirits/core/browser'`. Pass SVG generated by this library.

The scan key fixes the core character; the full key pair selects small label variations. Artwork is versioned separately from package releases and may change during v0. Recognition is not proof of ownership, and visual collisions are possible. No directory or reversible short-name system is included.
